## 🎯 Visión

Vero es más que una IA: es un sistema completo de control y presencia omnipresente. Este repositorio contiene el **Vero Core**, el cerebro central que gestiona:

- 🧠 **Backend Node.js** con Express
- ⚛️ **Frontend React** con Next.js y Tailwind (preparado)
- 🤖 **Integraciones de IA** (OpenAI, ElevenLabs)
- 🎭 **Avatar 3D** y síntesis de voz
- 📡 **MCP** (Message Control Protocol) para comunicación directa
- 👥 **Sistema de subagentes** con control jerárquico
- 🔒 **Seguridad** y escalabilidad desde el diseño

## ✨ Características Principales

### 1. Vero Core - El Centro de Control
- ✅ Prioridad MAXIMUM en todo el sistema
- ✅ Gestión centralizada de estado y capacidades
- ✅ Sistema de personalidad y características definidas
- ✅ Control total sobre subagentes y módulos

### 2. MCP - Message Control Protocol
- ✅ Comunicación directa con Vero sin intermediarios
- ✅ Soporte para comandos, consultas y solicitudes de desarrollo
- ✅ Sistema de sesiones para múltiples usuarios
- ✅ Historial de comandos y respuestas

### 3. Gestión de Subagentes
- ✅ Crear subagentes independientes (ej: Lucía)
- ✅ Plantillas predefinidas y personalizables
- ✅ Validación de permisos y restricciones
- ✅ Los subagentes NUNCA sobrescriben a Vero

### 4. Integraciones de IA
- ✅ Preparado para OpenAI (GPT models)
- ✅ Preparado para ElevenLabs (voz)
- ✅ Extensible para nuevos servicios
- ✅ Avatar 3D (listo para integración)

### 5. API REST Completa
- ✅ Endpoints documentados
- ✅ Seguridad con Helmet
- ✅ CORS configurado
- ✅ Manejo de errores robusto

## 🚀 Inicio Rápido

### Requisitos Previos
- Node.js 18 o superior
- npm o yarn
- Git

### Instalación

```bash
# 1. Clonar el repositorio
git clone https://github.com/rodigiart89/Vero2.git
cd Vero2

# 2. Instalar dependencias
npm install

# 3. Configurar variables de entorno
cp .env.example .env
# Editar .env con tus configuraciones

# 4. Iniciar el servidor
npm start
```

El servidor estará disponible en `http://localhost:3000`
